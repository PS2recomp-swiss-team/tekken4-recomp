# controls notes

## Findings (read, before edits)

- Port 0 production path is PSPadBackend::readState (ps2_pad.cpp). scePadRead uses it when the backend returns true (always for a 32-byte buffer). Pad.cpp applyGamepadState is the later-port path (findNthGamepad) and the port-0 fallback. applyKeyboardState is fallback only and its key table DIFFERS from ps2_pad (L2=1, Select=RightShift, WASD also drives the left stick). Defaults follow ps2_pad / vkToPad, and the fallback is aligned to that table.
- Today's keys (active-high masks): W up 0x0010, S down 0x0040, A left 0x0080, D right 0x0020, Down/X/Space cross 0x4000, Right/C/Esc circle 0x2000, Left/Z/Numpad0 square 0x8000, Up/V/Numpad1 triangle 0x1000, Q L1 0x0400, E R1 0x0800, LShift and VK_SHIFT L2 0x0100, RShift R2 0x0200, Enter start 0x0008, Tab select 0x0001. No L3/R3. No keyboard sticks. Gamepad is positional on raylib gamepad 0 (port 0) and the nth pad (later ports). Stick bytes on port 0 are `128 + axis*127` with NO deadzone. Pad.cpp fallback uses lround((axis+1)*127.5); that formula stays on the later-port path.
- padmap (not executed): presets playstation/xbox/switch are positional; switch-labels is A=Cross (RIGHT_FACE_RIGHT), B=Circle (RIGHT_FACE_DOWN), X=Square (RIGHT_FACE_UP), Y=Triangle (RIGHT_FACE_LEFT); keyboard preset ignores gamepads. Radial deadzone default 0.15, rescale (mag-dz)/(1-dz)/mag, zero at mag<=dz. invert_y true = right stick only; also left/both/none. stick_swap before invert. trigger_threshold null = digital LEFT/RIGHT_TRIGGER_2; when set, those sources become the trigger axes. Axis range: once a sample < -0.01, treat -1..1 as 0..1. Touch zones skipped (no Android).
- INTENTIONAL default change: radial deadzone 0.15 on both sticks (padmap). Full deflection is unchanged (scale 1). Values inside 0.15 become centre. Buttons, keys, and which device each port reads stay as today.
- Not changed on purpose: port 0 stays raylib pad 0 (not padmap "first"), later ports stay findNthGamepad(port), keyboard always merges on port 0. Rumble and pressure untouched. No edits to runtime/*_overrides.cpp.
- Fast path: posted WM_KEYDOWN is the fight script (run_capture.ps1 vk table). sampleKeyboard must keep one atomic posted-mask plus the 200 us GetAsyncKeyState cache. Key table is a published snapshot (3 slots), refreshed on settings load/set, not per read.
- Remap proof plan: PS2X_SETTINGS with CROSS=DOWN,C,SPACE and CIRCLE=RIGHT,X,ESCAPE. Posted X (0x58) becomes Circle, so the display-menu Cross confirm should fail (`menu step failed: display`) while Down (S) still moves the cursor. stderr `[controls] cross_keys=...` shows the table the hook published.
- Fight script VKs: Up W 0x57, Down S 0x53, Left A 0x41, Right D 0x44, Start Enter 0x0D, Select Tab 0x09, Cross X 0x58, Circle C 0x43, Square Z 0x5A, Triangle V 0x56.

## Implementation

- Mapping engine is in ps2_graphics_settings.h/.cpp (linked into ps2_runtime and ps2x_tests). No new cpp, no CMake edit, padmap's generated ps2_pad.cpp is not installed.
- Defaults: positional gamepad (playstation/xbox/switch share it), today's 22 keys, no stick keys, invert off, swap off, trigger digital. Deadzone 0.15 radial is the only intentional behaviour change. Port 0 bytes stay 128+v*127 (ps2_pad.cpp). Later ports keep axisToByte.
- Fast path: fillSnap writes vkMask/pollVk. vkToPad and asyncPadMask read publishedSnap (3 slots). VK_SHIFT 0x10 aliases left shift and is not polled. sampleKeyboard does no snap walk unless stickCount>0 (default 0). attachWindow calls ps2_graphics::get() before the hook.
- Pad.cpp later ports call mapGamepad + swap + invert/deadzone. Keyboard preset sets ignoreGamepads so port>0 reports disconnected. Port 0 stays keyboard + gamepad 0. Fallback applyKeyboardState uses the shared rlKeys; stick keys only in analog mode.
- F2 Controls is the first section, window (8,8), bind child 200px. Click replaces, right-click adds a key, x clears keys, Esc cancels, one skipped frame after arming. Suppress pad posting while capturing or ImGui wants text. Block gamepad buttons only while capturing. Gate atomics run only after the panel has drawn, so a hidden panel (the fight) does not touch them.
- Load/save uses controls_* lines on the existing PS2X_SETTINGS file. A successful fopen logs `[controls] ... cross_keys= circle_keys=` to stderr. No file: defaults, no log.
- Not built: per-port gamepad index, players, allow_duplicates, touch, rumble, pressure.
- Remap proof file will set controls_key_CROSS=DOWN,C,SPACE and controls_key_CIRCLE=RIGHT,X,ESCAPE. Posted X (0x58) becomes Circle, so display-menu Cross should fail after PAL60. Down (S) is unchanged.
