**Needs OpenRecomp-FGC 0.1.3 or newer** (0.1.4 recommended).

### Tekken 4 0.1.4 — nothing to download, nothing to install

- **Build downloads nothing any more.** The game program now comes ready-made in the release. Your PC only translates
  the game code from your own disc, with the compiler that is in the zip. No Microsoft files, no licence screen, no
  Visual Studio, no Git, no internet needed for Build.
- **Much faster first Build:** about 2 minutes (most of it is unpacking your disc), and a few seconds when nothing
  changed. 0.1.3 needed about 4 minutes plus a 240 MB download.
- **Smaller download:** about 136 MB for Tekken 4 (0.1.3: 274 MB).
- **Same build for every player**, whatever is installed on the PC. Everybody builds once more after updating.
- **Folders with special characters work** (for example a user name like Müller, or a Cyrillic folder name). Before,
  the game could not start from such a folder.
- Old processors without SSE4.1 get the matching version of the game program automatically (same game, you can play
  each other online).
- The zip is easier: start `Start OpenRecomp-FGC.cmd` at the top. The old standalone `Tekken4.cmd` is gone.

**Online:** 0.1.3 and 0.1.4 cannot play each other — update both players. Update the launcher first if yours is
older than 0.1.3 (Quick access → Check for launcher updates), then Tekken 4.
