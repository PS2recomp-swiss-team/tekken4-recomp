# Tekken 4 ranked: name plates in the game

Owner (2026-11-04): "Use Tekken 7 ranks in Tekken 4 ranked. It should also show a picture, and which side is who, with
names etc." The ranks and the ranked rules live in the T4 lobby server (its docs/T4_RANKED.md: Tekken 7's 47 rank names,
only results the games proved count, sets of best of 3) and the launcher (OpenRecomp-FGC: ranked button, badges,
match-found sides). This page is the game's part: each player's **name and rank badge on their side**.

## What the players see

Owner (2026-11-04): "instead of the CHARACTER name use the PLAYER's name, and the rank (badge) LEFT of the name".

- Where the game prints the fighter's name -- under each side's preview at VS character select (scene 7, VS Battle;
  the online games boot straight there, t4-autovs) and under each life bar in the fight (scene 4 with a round running)
  -- a dark panel covers it and shows `[badge] Player name`. P1 left-aligned, P2 right-aligned like the game's P2 name;
  the badge is directly left of the name on both sides, the panel grows for a long name.
- P1 is the host's side on both PCs, so both PCs show the same names on the same sides.
- Ranked and casual look the same: an account shows its T4 rank badge (casual matches too: the account has a rank),
  a guest shows the name only. Offline, or with the plates off, the game's own fighter names show.

## How

- `runtime/tekken4_hud_overrides.cpp`: reads guest RAM only (scene 0x357d38, game type 0x2a8bf8, the player objects'
  health and the round timer to know a round runs) and draws with raylib after the game's picture, through patch 88
  (`ps2_host_overlay.h`: one host-only overlay callback in the presenter). It never writes guest memory: the online
  state hash, rollback, lockstep and the result file are the same with and without plates.
- `runtime/tekken4_rank_badges.h`: the badges' design table (name, colours, emblem, pips), GENERATED by OpenRecomp-FGC
  `tools/make_rank_badges.py --header` -- the same script makes the launcher's SVG badges, so both show the same badge.
  Our own drawing; Tekken 7's rank NAMES only, never Namco's emblems.
- Text: Arial Bold from the PC's fonts (Segoe UI Bold, else raylib's own font); names are cut to 16 ASCII characters.

## Environment (set by the launcher / t4lobby.t4game.hud_env)

| Variable | |
|---|---|
| `TEKKEN4_HUD_NAMES` | `P1 name|P2 name` |
| `TEKKEN4_HUD_RANKS` | `P1 tier,P2 tier` (0..46, -1 = no badge) |
| `TEKKEN4_HUD_PLATES` | `0` = off (launcher Settings: "Name plates in the game") |
| `TEKKEN4_HUD_SHOTS` | test hook: `s,s,...` seconds after start -> `hud_<s>s.png` (the window: picture + plates) |
| `TEKKEN4_HUD_WINDOW` | test hook: `WxH` window size for those pictures |

Build: `tools\stage_generated.cmd` stages the override and the badge header; patch 88 applies with the series.
